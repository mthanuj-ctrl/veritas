# Veritas

Paste a news claim, social media post, or article link. Veritas tells you whether it is likely real or fake, explains why in one sentence, and shows what trustworthy sources say about it.

Backend: FastAPI + NumPy + SciPy.
Frontend: Plain HTML, CSS, JavaScript. No build step.
Data: Google News search (RSS, no key), optional Google Custom Search, Reddit public JSON.
